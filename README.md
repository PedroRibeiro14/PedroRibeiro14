<!--
  SNAKE CONFIGURATION

  The image above only works after the GitHub Actions
  workflow has generated and published the SVG.

  Create this file:

  .github/workflows/snake.yml

  Copy the following YAML into that separate file:

  ------------------------------------------------------

  name: Generate Snake

  on:
    schedule:
      - cron: "0 0 * * *"
    workflow_dispatch:

  permissions:
    contents: write

  jobs:
    generate:
      runs-on: ubuntu-latest

      steps:
        - name: Generate contribution snake
          uses: Platane/snk/svg-only@v3
          with:
            github_user_name: PedroRibeiro14
            outputs: |
              dist/github-contribution-grid-snake.svg
              dist/github-contribution-grid-snake-dark.svg?palette=github-dark

        - name: Publish SVG files
          uses: crazy-max/ghaction-github-pages@v3.2.0
          with:
            target_branch: output
            build_dir: dist
          env:
            GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

  ------------------------------------------------------

  SETUP:

  1. Create a public repository named PedroRibeiro14
     under the PedroRibeiro14 account.

  2. Add README.md to that repository.

  3. Create .github/workflows/snake.yml.

  4. Paste the YAML above without the comment prefixes.

  5. In Settings > Actions > General, configure
     workflow permissions to allow writing repository
     contents, if permitted by repository policy.

  6. Open Actions > Generate Snake > Run workflow.

  7. Check that the output branch contains the SVG.

  8. Refresh the profile page.

  For better supply-chain security, pin external
  GitHub Actions to audited commit SHAs.
-->
